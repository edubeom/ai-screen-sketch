- 2026-11-03 [AI] 지우개: 한 번 누르는 동안 지운 자리를 품은 바깥 요소는 지키고, 채우지 않은 모형은 테두리를 건드릴 때만 지움 -- "안에 있는 오브젝트만 삭제" (다른 안: 한 번 누름에 하나만 지우기 -- 문질러 여러 개 지우기가 안 됨)
- 2026-11-03 [AI] 공유기 접속은 portproxy 공유기 주소 → 127.0.0.1 (사용자의 3000·9000 규칙과 같은 방식) + 방화벽 개인 네트워크만, 스크립트로 제공하고 실행은 사용자 -- 재부팅에도 유지, Windows 설정 변경이라 사용자 권한 (다른 안: WSL mirrored 네트워크 -- WSL 재시작 필요)

- 2026-11-02 [사용자] 모형 인식은 펜이 멈췄을 때 여러 획을 이어서 본다 -- "네모나 세모나 한 획으로 작성하는 경우는 없다. 펜이 멈췄을 때, 그 선이 하나의 도형을 이루는지를 연결해서 볼 수 있어야 한다."
- 2026-11-02 [AI] 모형 인식을 순서 없는 틀 맞추기로 바꿈 (정확도 85% · 완성도 90%, 멈춤 0.7초) -- 여러 획·삐져나옴·덜 닫힘에 강함 (다른 안: 획 이어 붙이기 후 한 획 방식, 기계학습 인식기)
- 2026-11-02 [AI] 손으로 둘러싼 곳 채우기는 "칠한 영역" 모형(꼭짓점 목록)으로 저장 -- 같은 project.json·PNG·요청문으로 그대로 전달되고 다시 누르면 색만 바뀜 (다른 안: 그림(비트맵)으로 저장)
- 2026-11-02 [AI] 원격 데스크톱의 펜 버튼은 앱이 받을 수 없어 "키보드 키로 바꿔 등록" 을 안내하고 받은 입력 기록을 보여 줌 (다른 안: 원격 프로그램 설정 변경 -- 사용자 환경이라 제안만)

- 2026-11-02 [AI] 펜 버튼은 "등록(학습)" 방식 -- 브라우저는 펜 버튼을 포인터 버튼(2·1·5)이나 드라이버가 바꾼 키로만 받고 어느 쪽인지는 VEIKK 드라이버 설정에 달림. 기본값: 먼 버튼 = 펜 버튼 5·1, 가까운 버튼 = 펜 버튼 2 (다른 안: 고정 단축키만)
- 2026-11-02 [AI] 펜 버튼 1번 채우기는 "한 번 칠하면 이전 도구로" -- 펜으로 그리다 잠깐 칠하는 흐름. 위쪽 채우기 도구는 계속 유지 (다른 안: 둘 다 계속 유지)
- 2026-11-02 [AI] 지우개는 펜 아래 맨 위의 것 하나씩 (필기 → 위의 요소 → 아래 요소). 지운 요소를 대상으로 하던 동작은 깨진 연결로 남음 -- 사용자 요청 "뭐든 삭제" (다른 안: 필기만)
- 2026-11-02 [AI] 모형 인식은 손그림을 먼저 저장한 뒤 바꿔 Ctrl+Z 로 손그림으로 돌아갈 수 있게, 끄고 켜는 "모형 인식" 칸(기본 켬, 이 브라우저에 기억) -- 글씨가 모형으로 바뀌는 실수를 되돌리기 쉽게 (다른 안: 바꾸기 전에 묻기)
- 2026-11-02 [AI] 새 요소 종류 `shape`·바탕색은 선택 칸이라 schemaVersion 1 그대로 (다른 안: 2 로 올리기)
