## 지금 작업
### 작업: 펜 작업 개선 (저장 표시 · 지우개 · 모형 인식 · 채우기/색 · 펜 버튼)
- 목표: 펜만으로 그리고 지우고 색을 칠하고 되돌릴 수 있다
- 완료 기준:
  - [ ] 저장 표시가 가져오기 왼쪽에 있고, 저장 중/저장됨이 바뀌어도 위쪽 버튼들이 움직이지 않는다
  - [ ] 지우개로 필기뿐 아니라 텍스트·상자 등 어떤 요소든 지워진다 (실행 취소로 되돌아옴)
  - [ ] 손으로 네모·원·별(+세모·마름모)을 그리면 같은 크기의 모형으로 바뀌고, 모형 가운데를 누르면 글을 쓸 수 있다
  - [ ] 채우기 도구로 모형·요소·바탕에 색을 칠하고, 색 팝업(최근 4 · 기본 16 · 색 판)과 스포이트가 된다
  - [ ] 펜 버튼(먼 쪽: 1번 채우기 · 2번 색 팝업 · 3번 스포이트 / 가까운 쪽: 1번 실행 취소 · 2번 다시 실행 · 3번 지우개 전환)이 동작한다 -- 실제 VEIKK 펜은 사람 확인
- 건드릴 기능: 작업판 편집, 필기 (+ 설계 코어 계약에 모형·바탕색 추가, 상단 막대)
- 영향 받을 수 있는 기능: 내보내기·가져오기 (새 요소 종류 · 바탕색 -- 시험으로 왕복 확인), 동작·상태 명세 (지운 요소는 깨진 연결)
- 설명서: 고침 (sketch.html 지우개·필기 단계, 모형·채우기·펜 버튼 페이지 추가, 바뀐 점)
- 데이터: 브라우저에만 (project.json 에 선택 칸 추가 -- 예전 파일도 그대로 열림). 펜 버튼 설정은 이 브라우저 localStorage
- 진행: 만드는 중 (요청 = 범위 확인으로 보고 진행)
