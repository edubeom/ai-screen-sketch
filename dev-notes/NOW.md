## 이 프로젝트는
화면을 사각형·텍스트·필기·메모로 그리고 동작(트리거·조건·결과·실패 상태)을 붙여, AI 개발자에게 넘길 설계 묶음(ZIP: project.json·PNG·requirements.md·manifest.json)을 만드는 단독 실행 웹 스케치 도구.
기준 문서: `doc/PRD/AI_Screen_Sketch_Tool_Plan_v1.docx` (v1.1, 2026-10-28). 이번 목표는 기획서 6장의 단계 1~2(PC 스케치 + 의도 전달)까지의 최초 프로토타입.

## 지금 작업
### 작업: 최초 프로토타입 (기획서 단계 1~2) -- 6단계로 나눔
- 목표: 프레임워크 없는 PC 브라우저에서 화면을 그리고 동작·상태를 붙여 ZIP 설계 묶음으로 내보내고 다시 가져와 같은 화면을 재현한다
- 완료 기준:
  - [ ] 화면을 여러 개 만들고 영역·텍스트·버튼·입력창·목록·카드·이미지·메모·연결선과 캘린더·작업 목록 프리셋을 놓고 선택·이동·크기 조절할 수 있다
  - [ ] 펜 모드에서 그린 필기가 확대·축소 후에도 같은 자리에 있다
  - [ ] 작업 카드 → 캘린더 시간 칸 드롭 동작을 조건·결과·예외·검증 기준과 함께 적고, 빈 목록·오류 상태를 붙일 수 있다
  - [ ] 브라우저를 닫았다 열어도 마지막 저장 상태가 돌아온다 (상단에 저장 중·저장됨·실패 표시)
  - [ ] ZIP(project.json·화면별 PNG·assets·requirements.md·manifest.json, Light 선택 시 task-card.md·traceability.json)을 내보내고, 다시 가져오면 위치·문구·필기·연결이 같다
- 단계: ① 설계 코어 ② 작업판 편집 ③ 필기·편집 명령·실행 취소 ④ 로컬 저장 ⑤ 동작·상태 명세와 검증 ⑥ 내보내기·가져오기·Light/전문판 전달물 + AHNDA 예시 + 설명서
- 건드릴 기능: 모두 새 기능 (FEATURES.md)
- 영향 받을 수 있는 기능: 없음 (새 프로젝트)
- 설명서: 새로 만듦 (manual/ -- 단계 ⑥에서)
- 데이터: 브라우저에만 (IndexedDB 저장 이름은 NAMES.md)
- 진행: 만드는 중 (① 설계 코어 끝)
